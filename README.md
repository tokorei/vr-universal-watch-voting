# VR Universal — Watch Voting & Decision Portal

Interactive internal team selection and voting suite for the **VR Universal Military Defence System Edition** timepiece.

## Features
- **18 Front Dial Variations**: 
  - Designs 01–12: Tactical, Mil-Spec, Field, Diver, Armored, and Factory Reference 1:1 Plaque Edition.
  - Designs 13–18: Homages to legendary watchmakers (IWC Schaffhausen, Rolex Explorer, Panerai Luminor, Bell & Ross Cockpit, Audemars Piguet Royal Oak, Breitling Navitimer).
- **7 Laser-Engraved Casebacks**:
  - Mechanical keep-out zone compliance (guaranteed $\ge 2.13\text{ mm}$ clearance from tool opening notches).
  - Continuous $170^\circ$ specification text arcs without clipping.
- **Dynamic View Controls**:
  - Dial Only (Macro) vs. With Silicone Strap (Olive Green, Tactical Black, Navy Blue).
  - Artwork Only vs. With Watch Needles.
- **On-Page Analytics Dashboard**:
  - Live vote tallies, percentage bar charts, and individual voter records.
